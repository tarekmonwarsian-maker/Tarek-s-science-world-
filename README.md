# Tarek Monwar's Science World

**Tarek Monwar's Science World Foundation** — বিজ্ঞান অলিম্পিয়াড, প্রজেক্ট, গবেষণা ও AI সহায়তায় পরিচালিত একটি অলাভজনক ফাউন্ডেশনের অফিসিয়াল ওয়েবসাইট।

## প্রতিষ্ঠাতা ও প্রেসিডেন্ট
**তারেক মনোয়ার সানিয়াত**

## ফিচারসমূহ
- 🏠 আধুনিক হোমপেজ ও হিরো সেকশন
- 📖 আমাদের সম্পর্কে + প্রতিষ্ঠাতার পরিচিতি
- 🖼️ গ্যালারি
- 📚 প্রকাশনা ও অর্জন
- 📢 নোটিশ বোর্ড
- 🤖 AI বিজ্ঞান সহায়ক (সিমুলেটেড — Gemini API যোগ করা যাবে)
- 🧠 বিজ্ঞান কুইজ (১০টি প্রশ্ন)
- 🔐 লগইন / সাইন আপ (LocalStorage ভিত্তিক)
- 📱 সম্পূর্ণ রেসপন্সিভ (মোবাইল ফ্রেন্ডলি)

## কিভাবে চালাবেন

### লোকালভাবে
1. এই ফোল্ডারটি ডাউনলোড করুন
2. `index.html` ফাইলটি ব্রাউজারে খুলুন

### GitHub Pages-এ পাবলিশ
1. নতুন GitHub রিপোজিটরি তৈরি করুন
2. সব ফাইল আপলোড করুন
3. Settings → Pages → Source: Deploy from a branch → main / root
4. কিছুক্ষণ পর আপনার সাইট লাইভ হবে

## ভবিষ্যৎ উন্নয়ন
- Google Gemini API ইন্টিগ্রেশন (AI চ্যাটের জন্য)
- Firebase / Supabase দিয়ে রিয়েল ইউজার অথেন্টিকেশন
- অ্যাডমিন প্যানেল (নোটিশ, গ্যালারি, প্রকাশনা ম্যানেজমেন্ট)
